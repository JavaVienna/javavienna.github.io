  title: Model Driven Architecture & Design @ ING-DiBa
  description: |-
    Markus and Claudiu from ING DiBa will give us an introduction on Model Driven Architecture (MDA) and Model Driven Design (MDD) and how these are used at ING DiBa on a daily basis to define the architecture of ING DiBa`s Applications and how code gets generated from the models for the various application layers. Aside from the typical candidates like Persistence and DTOs, we'll also see how those definitions are used to model processes.

    Markus will share his perspective as an architect, while Claudiu will talk about the everyday use of these approaches from a developers point of view.
